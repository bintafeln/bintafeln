Der automatische Abruf ist auf diesem Server nicht eingeschaltet. Finanzexport und Spenderliste lassen sich jederzeit von Hand hochladen.

Zum Einschalten trägt die Person, die den Server betreut, in der Datei .env COMPOSE_PROFILES=abruf und einen BINTAFELN_ABRUF_SCHLUESSEL ein und führt ./betrieb update aus. Mehr dazu im Handbuch.

{% else %}

bintafeln meldet sich in WISO MeinVerein an, holt den Finanzexport für den Zeitraum (und auf Wunsch die Liste „Spender mit E-Mail“) und liest beides ein. Sie geben nur den 2FA-Code ein, wenn danach gefragt wird. Höchstens drei Monate auf einmal.

Was passiert, wenn ich die Seite verlasse?
  • Der Abruf läuft auf dem Server weiter – auch wenn Sie eine andere Seite öffnen, das Fenster schließen oder sich abmelden. Anmelden und Herunterladen dauern oft einige Minuten.
  • Bis zum 2FA-Code bitte hierbleiben: Fragt WISO MeinVerein nach dem Code, muss er innerhalb von 5 Minuten hier eingegeben werden – nur von Ihnen, wenn Sie den Abruf gestartet haben. Sonst bricht der Abruf ab.
  • Eingelesen wird beim nächsten Öffnen dieser Seite: Sind die Dateien geladen, liest bintafeln sie ein, sobald jemand mit dem Recht diese Seite wieder öffnet. Bis dahin warten sie auf dem Server. Das Ergebnis steht danach unten unter „Bisherige Abrufe“.
  • Während ein Abruf läuft, kann niemand einen zweiten starten. Wird der Server in der Zwischenzeit neu gestartet (z. B. bei einem Update), geht ein noch nicht eingelesener Abruf verloren – dann einfach neu starten. Schon Eingelesenes wird nie doppelt angelegt.
