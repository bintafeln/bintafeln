Sicherungen

Der Server sichert Datenbank und hochgeladene Dateien verschlüsselt. Jeder Auftrag legt fest, wohin, an welchen Tagen und wie lange die Stände aufbewahrt werden. „Jetzt sichern“ geht immer, auch bei ausgeschalteten Aufträgen. Wiederherstellen: ./betrieb wiederherstellen auf dem Server (siehe Hilfe).

Sicherung außer Haus

Weil die Sicherungen bereits verschlüsselt sind, kann man sie auf einen fremden Speicher legen – dort sieht niemand den Inhalt. Richtet man hier eine Fernablage ein (per rclone: SFTP, FTP, S3/Backblaze/Hetzner, WebDAV/Nextcloud …), kann man sie bei einem Sicherungsauftrag oben als Ziel wählen. Der Schlüssel zum Entschlüsseln bleibt getrennt – bewahren Sie ihn sicher auf, sonst nützt die Fernsicherung nichts.
