bintafeln läuft auf einem eigenen Server der Tafel. Die Pflege erledigt die technisch verantwortliche Person auf dem Server mit dem Befehl ./betrieb:

  • ./betrieb update – neue Version einspielen (auch ältere wählbar)
  • ./betrieb sichern – sofort sichern; ./betrieb status – Stand ansehen
  • ./betrieb wiederherstellen – eine Sicherung zurückspielen

Auf der Startseite sehen Sie den Stand der letzten Sicherung. Rot oder „veraltet“: bitte sofort der technisch verantwortlichen Person Bescheid geben. Die ausführliche Anleitung steht in der Datei README im Programmpaket.
