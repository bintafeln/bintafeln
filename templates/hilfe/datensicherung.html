Der Server sichert automatisch und verschlüsselt (Kapitel „Sicherungen“). Zusätzlich können Sie unter „Einstellungen → Export und Zurücklesen“ selbst eine Datei mit eigenem Passwort erzeugen und extern aufbewahren.

{% if "daten.exportieren" in rechte %}

Exportieren

  1. Bereiche wählen (alle = vollständige Sicherung).
  2. Ein Passwort festlegen (mindestens 10 Zeichen) – gut aufbewahren, ohne Passwort ist die Datei nicht lesbar.
  3. „Export herunterladen“ und die Datei sicher ablegen (z. B. verschlossener USB-Stick).
{% hilfe_bild "datensicherung-export" "① Bereiche wählen, ② Passwort zweimal eingeben, ③ „Export herunterladen“." %}{% endif %} {% if "daten.importieren" in rechte %}

Zurücklesen

  1. Datei und Passwort wählen, „Prüfen“. Noch ändert sich nichts. {% hilfe_bild "datensicherung-zuruecklesen" "① Exportdatei wählen, ② ihr Passwort eingeben, ③ „Prüfen (noch nichts ändern)“." %}
  2. Die Vorschau zeigt, was neu ist und was überschrieben würde.
  3. Aktualisieren: fügt hinzu und überschreibt gleiche Datensätze, löscht nichts – auch für Teildateien.
  4. Vollständig ersetzen: nur mit vollständiger Datei, nur mit Server-Sicherung von heute und Bestätigung; z. B. beim Umzug auf einen neuen Server.
