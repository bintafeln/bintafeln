Mit der Zwei-Faktor-Anmeldung reicht ein gestohlenes Passwort nicht aus: Zusätzlich braucht man einen Code vom eigenen Handy. Für manche Rollen ist sie Pflicht; dann führt bintafeln nach der Anmeldung direkt zur Einrichtung.

Einrichten

  1. Eine Authenticator-App auf dem Handy installieren (z. B. „FreeOTP“, „Aegis“, „Google Authenticator“ oder „Microsoft Authenticator“).
  2. „Mein Konto“ → „Jetzt einrichten“. Den QR-Code mit der App scannen.
  3. Den sechsstelligen Code aus der App eintippen und bestätigen.
  4. Es erscheinen einmalig 10 Notfallcodes. Ausdrucken oder abschreiben und sicher aufbewahren – jeder funktioniert genau einmal anstelle der App.

So läuft die Anmeldung

Zuerst nur Benutzername und Passwort. Ist für Ihr Konto Zwei-Faktor eingerichtet, erscheint danach ein eigenes Fenster für den Code aus der App (oder einen Notfallcode). Das Fenster gilt 5 Minuten; nach 5 falschen Codes beginnt die Anmeldung von vorn.

Handy verloren oder neu?

Mit einem Notfallcode anmelden und unter „Mein Konto“ neu einrichten. Ohne Notfallcode kann ein Admin oder das Büro die Zwei-Faktor-Anmeldung bei „Mitarbeitende“ zurücksetzen.

Diesem Gerät vertrauen

Hat die Tafel es eingeschaltet, steht im Fenster für den Code „Diesem Gerät … Tage vertrauen“. Mit Haken (und Code) fragt bintafeln auf diesem Browser so lange nicht mehr nach dem Code – nur nach dem Passwort. Nur an eigenen bzw. Tafel-Geräten anhaken, nie an fremden oder öffentlichen. Unter „Mein Konto“ sehen Sie Ihre vertrauten Geräte und können sie entfernen. Ein gutes Passwort

  • Lang statt kompliziert: z. B. vier zufällige Wörter.
  • Nirgends sonst verwenden und niemandem weitergeben – auch nicht Kolleginnen und Kollegen.
  • Ändern unter „Mein Konto“ → „Passwort ändern“.
