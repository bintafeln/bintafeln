Unter „Einstellungen → Update“ spielen Sie eine neue Version von bintafeln ein, ohne den Server zu bedienen.

  1. Die Seite zeigt die installierte Version und oben deutlich „Neue Version … verfügbar“ oder „bintafeln ist aktuell“, darunter die neuen Versionen mit ihren Änderungen („Was ist neu?“, je Änderung mit Stichpunkten). Die Liste bleibt während des Updates und danach stehen („Neu mit dem Update auf …“). bintafeln sucht alle 10 Minuten selbst; „Jetzt nach neuen Versionen suchen“ zeigt, solange gesucht wird, „Suche läuft …“.
  2. Version wählen (vorgewählt ist die neueste), bestätigen und „Update starten“.
  3. bintafeln sichert zuerst automatisch, holt dann die neue Version und startet neu. Das dauert meist ein bis zwei Minuten; in der Zeit ist bintafeln nicht erreichbar. Das Protokoll lässt sich währenddessen aufklappen und läuft dann mit. Die Seite meldet sich danach von selbst mit dem Ergebnis. Nicht mehr benötigte alte Programmstände räumt das Update selbst weg, damit die Festplatte nicht volläuft.
Updates am besten zu einer Zeit einspielen, in der keine Ausgabe läuft.

Zurück auf eine ältere Version

Macht eine neue Version Probleme, lässt sich in derselben Liste eine ältere wählen („älter, zurückgehen“). Was nur die neuere Version gespeichert hat (z. B. neue Felder), geht dabei verloren; vorher wird gesichert.

Wenn etwas nicht klappt

  • „Der Update-Dienst läuft noch nicht“: Einmalig auf dem Server ./betrieb update ausführen; ab dann geht es hier.
  • „Neue Versionen konnten nicht abgerufen werden“: Der Server erreicht GitHub nicht (Internet, Zugangsdaten). Der Dienst nutzt dieselben Zugangsdaten wie die Person, der der bintafeln-Ordner auf dem Server gehört. Klappt git fetch dort auf der Kommandozeile, klappt es auch hier. Bei „Host key verification failed“ nach einem Update von einer älteren Version einmalig ./betrieb update auf dem Server ausführen.
  • Update fehlgeschlagen: Das Protokoll auf der Seite zeigt, woran es lag. Meist läuft der bisherige Stand weiter; die technisch verantwortliche Person kann mit dem Protokoll helfen.
