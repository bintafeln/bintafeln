# Beispieldateien für den Import

Alle Namen, Anschriften und Nummern sind **erfunden**. Die Dateien zeigen das Format aus
[../../importformat.md](../../importformat.md) und dienen später auch als Testdaten.

Die Spalte `zusatz_schwerbehindert` setzt voraus, dass die Tafel vorher ein Zusatzfeld mit dem
Schlüssel `schwerbehindert` (gilt für Person, Typ Ja/Nein oder Auswahl) angelegt hat.
